# 윈도우 9·10 (agree55) 가설 – 예측값 사용 방식

## 1. 실시간 계산인가? 테이블 조회인가?

**이 가설은 예측값을 실시간으로 계산하지 않습니다.**

- **미리 생성된 테이블** `simulation_predictions_change_point`에서만 예측값을 **조회**합니다.
- 검증 시 테이블에서 **빈도 기반**·**가중치 기반** 두 행을 읽어 비교합니다.
- **반드시** 「예측값 테이블 생성」으로 테이블을 채운 뒤 시뮬레이션을 실행합니다.

---

## 2. 테이블 생성 시 임계값

**이 가설에서 테이블을 생성할 때 임계값은 항상 0입니다.**

- 「예측값 테이블 생성」 버튼을 누르면 `threshold=0`으로 저장됩니다.
- 검증 시에도 테이블 조회는 **항상 threshold=0**으로만 합니다.
- 따라서 **테이블의 threshold 컬럼**은 “저장 시 사용한 값”일 뿐, **예측을 쓸지 말지는 신뢰도로만** 결정합니다.

---

## 3. 예측 사용 조건: 신뢰도(confidence) 기준

**예측값을 사용할지 여부는 테이블의 threshold가 아니라 신뢰도(confidence)로만 결정됩니다.**

- **빈도 임계값(기본 51%)**: 빈도 기반 행의 **신뢰도(confidence)** 가 이 값 **이상**이어야 함.
- **가중치 임계값(기본 51%)**: 가중치 기반 행의 **신뢰도(confidence)** 가 이 값 **이상**이어야 함.
- **둘 다 충족**할 때만 해당 스텝에서 예측을 사용합니다. (그리고 빈도·가중치 예측값이 같아야 함.)

즉, “51 이상”은 **신뢰도가 51% 이상**이라는 뜻이며, 테이블의 threshold와는 무관합니다.

---

## 4. “모든 스텝에서 예측값이 없다”가 나오는 경우

| 원인 | 설명 |
|------|------|
| **테이블 미생성** | agree55용으로 「예측값 테이블 생성」을 하지 않았거나, 테이블이 비어 있는 경우. |
| **기준 ID 불일치** | 테이블 생성 시 **기준 Grid String ID**와 시뮬레이션 실행 시 **기준 ID**가 다르면, 검증 prefix가 테이블에 없을 수 있음. |
| **신뢰도 미달** | 테이블에는 행이 있지만, 빈도/가중치 **신뢰도**가 설정한 % 미만이면 스킵됨. (테이블 threshold와 무관.) |

**참고:** 이 가설에서는 테이블 생성·조회 모두 **threshold=0**으로 고정이므로, “테이블 조회 threshold”를 따로 맞출 필요는 없습니다.

---

## 5. 요약

| 항목 | 내용 |
|------|------|
| 예측값 계산 | **실시간 계산 없음** → **테이블 조회만** |
| 사용 테이블 | `simulation_predictions_change_point` |
| 테이블 생성 시 임계값 | **항상 0** |
| 테이블 조회 | **항상 threshold=0** 으로 조회 |
| 예측 사용 조건 | **신뢰도(confidence)** 기준: 빈도 ≥ 빈도 임계값(기본 51%), 가중치 ≥ 가중치 임계값(기본 51%), 둘 다 충족 시에만 사용 (테이블 threshold와 무관) |
| 테이블에 필요한 것 | **빈도 기반** + **가중치 기반** 둘 다 저장 |
